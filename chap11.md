# Chapter 11: Geometry of the γ-Deformation

---

In Chapter 10, we introduced the $\gamma$-family

$$d_\gamma(b_i, b_j) = \sqrt{d(b_i, b_j)^2 + \gamma^2 D(b_i, b_j)^2}, \qquad \gamma \in [0, 1],$$

and established its basic properties: the triangle inequality (Theorem 10.9), monotonicity in $\gamma$ (Proposition 10.6), the norm-space interpretation (Proposition 10.20), the phase formula (Proposition 10.36), the nesting of $\gamma$-balls (Proposition 10.31), and the monotonicity of the induced topologies (Proposition 10.33).

This chapter develops the *geometry* of the deformation in detail. We study phase transitions, geodesics, diameter, and curvature, and we interpret the family as a continuous deformation of the geometry of belief space. The central new object is the **$\gamma$-phase transition**: a value of $\gamma$ at which the geometry changes discontinuously.

**Remark 11.0 (Relation to Chapter 10).** The basic definitions and properties of the $\gamma$-family—balls, topologies, monotonicity, the norm-space interpretation—were established in Chapter 10. This chapter does not repeat them; it cross-references them and builds on them. The reader who wants only the algebraic and metric properties of the $\gamma$-family can read Chapter 10; the reader who wants the geometric structure should read both.

---

## 11.1 Phase transitions

We begin with the central new concept of this chapter.

**Definition 11.1 (Phase transition).** A value $\gamma_c \in [0, 1]$ is a **$\gamma$-phase transition** if the topology $\tau_\gamma$ changes at $\gamma_c$. More precisely, $\gamma_c$ is a phase transition if there exist $\gamma_1 < \gamma_c < \gamma_2$ such that $\tau_{\gamma_1} \neq \tau_{\gamma_2}$.

**Remark 11.2.** The topology $\tau_\gamma$ was defined in Chapter 10, Definition 10.33. It is the topology generated by the $\gamma$-balls $B_\gamma(b, r) = \{b' : d_\gamma(b, b') < r\}$.

**Proposition 11.3 (Monotonicity of topologies).** For $\gamma \le \gamma'$, we have $\tau_{\gamma'} \subseteq \tau_\gamma$.

*Proof.* This is Proposition 10.33 in Chapter 10: the $\gamma$-balls are nested, so a set open in $\tau_{\gamma'}$ is open in $\tau_\gamma$. $\square$

**Remark 11.4.** The topology becomes coarser as $\gamma$ increases. At $\gamma = 0$, the topology is the finest (the topology of $d$); at $\gamma = 1$, the topology is the coarsest (the topology of $|Q|$).

**Proposition 11.5 (Equality of topologies).** If $\tau_0 = \tau_1$, then $\tau_\gamma = \tau_0$ for all $\gamma \in [0, 1]$.

*Proof.* By monotonicity, $\tau_0 \supseteq \tau_\gamma \supseteq \tau_1$ for all $\gamma \in [0, 1]$. If $\tau_0 = \tau_1$, then all inclusions are equalities. $\square$

**Remark 11.6.** The interesting case is when $\tau_0 \neq \tau_1$. In this case, there must be at least one phase transition, by the following proposition.

**Proposition 11.7 (Existence of transitions).** If $\tau_0 \neq \tau_1$, then there exists at least one $\gamma_c \in (0, 1)$ at which the topology changes.

*Proof.* The map $\gamma \mapsto \tau_\gamma$ is monotone (Proposition 11.3). If $\tau_0 \supsetneq \tau_1$, then the map is not constant, so there must be at least one value at which it changes. $\square$

**Definition 11.8 (Critical set).** The **critical set** of the $\gamma$-family is

$$\Gamma_c := \{\gamma \in [0, 1] : \tau_\gamma \text{ changes at } \gamma\}.$$

**Proposition 11.9 (Finitely many critical values for finite spaces).** If $\mathcal{B}$ is finite, then $\Gamma_c$ is finite.

*Proof.* The topology $\tau_\gamma$ is determined by the balls $B_\gamma(b, r)$, which are determined by the values $d_\gamma(b, b')$ for $b, b' \in \mathcal{B}$. These are continuous functions of $\gamma$, and the topology changes only when the order of these values changes or when a ball crosses a threshold. There are finitely many such events. $\square$

**Remark 11.10.** For infinite $\mathcal{B}$, $\Gamma_c$ may be infinite or even a continuous set. The analysis is more delicate and is not pursued here.

## 11.2 Characterization of phase transitions

We now characterize phase transitions in terms of the underlying geometry.

**Definition 11.11 (Comparison function).** For a pair $(b_i, b_j)$ with $d(b_i, b_j) > 0$, define the **debt-to-cost ratio**

$$r(b_i, b_j) := \frac{|D(b_i, b_j)|}{d(b_i, b_j)}.$$

For pairs with $d(b_i, b_j) = 0$ and $D(b_i, b_j) \neq 0$, we set $r(b_i, b_j) := +\infty$.

**Proposition 11.12 (Order preservation).** The order of the $\gamma$-distances $d_\gamma(b_i, b_j)$ and $d_\gamma(b_k, b_l)$ for two pairs is preserved as $\gamma$ varies if and only if the ratios $r(b_i, b_j)$ and $r(b_k, b_l)$ are equal.

*Proof.* We have

$$\frac{d_\gamma(b_i, b_j)^2}{d_\gamma(b_k, b_l)^2} = \frac{d(b_i, b_j)^2 + \gamma^2 D(b_i, b_j)^2}{d(b_k, b_l)^2 + \gamma^2 D(b_k, b_l)^2}.$$

This ratio is constant in $\gamma$ if and only if the vectors $(d(b_i, b_j), D(b_i, b_j))$ and $(d(b_k, b_l), D(b_k, b_l))$ are proportional, which is equivalent to $r(b_i, b_j) = r(b_k, b_l)$. Otherwise, the ratio is a non-constant rational function of $\gamma$, and the order can change. $\square$

**Remark 11.13.** The debt-to-cost ratio $r(b_i, b_j)$ is the cotangent of the phase: $r = \cot\theta$. So the ratios $r$ and the phases $\theta$ encode the same information.

**Theorem 11.14 (Phase transitions and ratio crossings).** A phase transition occurs at $\gamma_c$ if and only if there exist two pairs $(b_i, b_j)$ and $(b_k, b_l)$ with $r(b_i, b_j) \neq r(b_k, b_l)$ such that the order of $d_\gamma(b_i, b_j)$ and $d_\gamma(b_k, b_l)$ changes at $\gamma_c$.

*Proof.* The topology is determined by the balls, which are determined by the distances. The distances change order only when two of them cross, which happens exactly when the ratios cross. $\square$

**Remark 11.15.** The theorem says that phase transitions are determined by the *relative geometry* of the pairs, specifically by the ratios $r(b_i, b_j)$. This is a clean characterization.

**Example 11.16 (Phase transition).** Let $\mathcal{B} = \{1, 2, 3\}$ with

$$d = \begin{pmatrix} 0 & 1 & 2 \\ 1 & 0 & 1 \\ 2 & 1 & 0 \end{pmatrix}, \qquad D = \begin{pmatrix} 0 & 0 & 3 \\ 0 & 0 & 0 \\ -3 & 0 & 0 \end{pmatrix}.$$

Compute:

- $d_\gamma(1, 2) = 1$, $D(1, 2) = 0$, so $r(1, 2) = 0$.
- $d_\gamma(2, 3) = 1$, $D(2, 3) = 0$, so $r(2, 3) = 0$.
- $d_\gamma(1, 3) = \sqrt{4 + 9\gamma^2}$, $D(1, 3) = 3$, so $r(1, 3) = 3/2$.

At $\gamma = 0$: $d_0(1, 2) = d_0(2, 3) = 1$, $d_0(1, 3) = 2$. The ball $B_0(1, 2.5)$ contains $2$ and $3$.

At $\gamma = 1$: $d_1(1, 2) = 1$, $d_1(2, 3) = 1$, $d_1(1, 3) = \sqrt{13} \approx 3.606$. The ball $B_1(1, 2.5)$ contains $2$ but not $3$.

The critical value is $\gamma_c$ such that $\sqrt{4 + 9\gamma_c^2} = 2.5$, i.e., $4 + 9\gamma_c^2 = 6.25$, i.e., $\gamma_c^2 = 0.25$, i.e., $\gamma_c = 0.5$.

At $\gamma_c = 0.5$, the point $3$ leaves the ball $B_\gamma(1, 2.5)$. This is a phase transition: the topology changes at $\gamma_c = 0.5$.

**Remark 11.17.** The example shows that phase transitions occur at non-trivial values of $\gamma$. The critical value depends on the specific geometry of $d$ and $D$.

## 11.3 Geodesics and optimal paths

We now turn to geodesics.

**Definition 11.18 ($\gamma$-geodesic).** A path $\gamma = (b_0, b_1, \ldots, b_n)$ is a **$\gamma$-geodesic** if it minimizes the total $\gamma$-distance:

$$\sum_{k=0}^{n-1} d_\gamma(b_k, b_{k+1}) = d_\gamma(b_0, b_n).$$

**Proposition 11.19 (Characterization of geodesics).** A path is a $\gamma$-geodesic if and only if each intermediate step is optimal in the $\gamma$-metric.

*Proof.* By the triangle inequality for $d_\gamma$ (Theorem 10.9), the total distance is at least $d_\gamma(b_0, b_n)$, with equality if and only if the path is optimal. $\square$

**Definition 11.20 ($\gamma$-shortest path).** The **$\gamma$-shortest path** between $b_i$ and $b_j$ is any path that achieves the minimum of $\sum d_\gamma$ over all paths from $b_i$ to $b_j$.

**Proposition 11.21 (Dependence on $\gamma$).** The set of $\gamma$-shortest paths depends on $\gamma$ in general.

*Proof.* The $\gamma$-distance depends on $\gamma$, so the optimal path may change as $\gamma$ varies. $\square$

**Definition 11.22 (Path transition).** A value $\gamma_c \in [0, 1]$ is a **path transition** if the set of $\gamma$-shortest paths changes at $\gamma_c$.

**Theorem 11.23 (Path transitions and ratio crossings).** A path transition occurs at $\gamma_c$ if and only if there exist two paths $\gamma_1$ and $\gamma_2$ between the same endpoints whose total $\gamma$-costs cross at $\gamma_c$.

*Proof.* The $\gamma$-shortest path is determined by comparing the total $\gamma$-costs of all paths. The optimal path changes only when two path costs cross. $\square$

**Example 11.24 (Path transition).** Let $\mathcal{B} = \{1, 2, 3\}$ with:

- Path A: $1 \to 3$ directly, with $d(1, 3) = 4$, $D(1, 3) = 0$.
- Path B: $1 \to 2 \to 3$, with $d(1, 2) = 2$, $D(1, 2) = 3$, $d(2, 3) = 1$, $D(2, 3) = 0$.

At $\gamma = 0$: Path A costs $4$; Path B costs $2 + 1 = 3$. Path B is shorter.

At $\gamma = 1$: Path A costs $4$; Path B costs $\sqrt{4 + 9} + 1 = \sqrt{13} + 1 \approx 4.606$. Path A is shorter.

The critical value is $\gamma_c$ such that $\sqrt{4 + 9\gamma_c^2} + 1 = 4$, i.e., $\sqrt{4 + 9\gamma_c^2} = 3$, i.e., $4 + 9\gamma_c^2 = 9$, i.e., $\gamma_c^2 = 5/9$, i.e., $\gamma_c = \sqrt{5}/3 \approx 0.745$.

For $\gamma < \gamma_c$, Path B is shorter; for $\gamma > \gamma_c$, Path A is shorter. This is a path transition at $\gamma_c = \sqrt{5}/3$.

**Remark 11.25.** The example shows that the optimal path can change as $\gamma$ varies. This is a "geodesic transition," analogous to a phase transition but for optimal paths rather than topologies.

**Proposition 11.26 (Finitely many path transitions).** If $\mathcal{B}$ is finite, then the set of $\gamma$ at which the optimal path changes is finite.

*Proof.* The optimal path is determined by the comparison of finitely many path costs, each a continuous function of $\gamma$. The minimum changes only when two path costs cross, which happens at finitely many $\gamma$. $\square$

**Remark 11.27.** For infinite $\mathcal{B}$, there may be infinitely many path transitions. The analysis is more delicate.

## 11.4 The $\gamma$-diameter

We now study the diameter of belief space in the $\gamma$-metric.

**Definition 11.28 ($\gamma$-diameter).** The **$\gamma$-diameter** of $\mathcal{B}$ is

$$\mathrm{diam}_\gamma(\mathcal{B}) := \sup_{b_i, b_j \in \mathcal{B}} d_\gamma(b_i, b_j).$$

**Proposition 11.29 (Monotonicity of diameter).** $\mathrm{diam}_\gamma(\mathcal{B})$ is non-decreasing in $\gamma$.

*Proof.* $d_\gamma \le d_{\gamma'}$ for $\gamma \le \gamma'$ (Proposition 10.6), so the supremum is non-decreasing. $\square$

**Proposition 11.30 (Diameter formula).**

$$\mathrm{diam}_\gamma(\mathcal{B}) = \sup_{b_i, b_j} \sqrt{d(b_i, b_j)^2 + \gamma^2 D(b_i, b_j)^2}.$$

*Proof.* Direct from the definition of $d_\gamma$. $\square$

**Example 11.31.** If $\mathcal{B}$ is finite, the diameter is finite for all $\gamma$. If $\mathcal{B}$ is infinite, the diameter may be infinite.

**Remark 11.32.** The diameter is a crude measure of the "size" of belief space. It is monotone in $\gamma$, increasing as debt is weighted more heavily.

## 11.5 The $\gamma$-curvature

We now introduce the notion of $\gamma$-curvature, which measures the failure of the triangle inequality to be sharp.

**Definition 11.33 ($\gamma$-curvature).** The **$\gamma$-curvature** of a triple $(b_i, b_j, b_k)$ is

$$\kappa_\gamma(b_i, b_j, b_k) := d_\gamma(b_i, b_j) + d_\gamma(b_j, b_k) - d_\gamma(b_i, b_k).$$

**Proposition 11.34.** $\kappa_\gamma \ge 0$ for all triples.

*Proof.* Triangle inequality for $d_\gamma$ (Theorem 10.9). $\square$

**Proposition 11.35.** $\kappa_\gamma = 0$ if and only if the path through $b_j$ is a $\gamma$-geodesic.

*Proof.* Definition of geodesic. $\square$

**Remark 11.36.** The $\gamma$-curvature measures the "excess" of the path through $b_j$ over the direct transition. It is non-negative, and zero if and only if the path is geodesic.

**Proposition 11.37 (Non-monotonicity of curvature).** The $\gamma$-curvature $\kappa_\gamma(b_i, b_j, b_k)$ is not necessarily monotone in $\gamma$.

*Proof.* We give an explicit counterexample. Let $d(b_i, b_j) = 1$, $D(b_i, b_j) = 0$; $d(b_j, b_k) = 1$, $D(b_j, b_k) = 0$; $d(b_i, b_k) = 1.5$, $D(b_i, b_k) = 1$. Then:

- $\kappa_0 = 1 + 1 - 1.5 = 0.5$.
- $\kappa_1 = 1 + 1 - \sqrt{1.5^2 + 1^2} = 2 - \sqrt{3.25} \approx 2 - 1.803 = 0.197$.

So $\kappa_\gamma$ decreases from $0.5$ to $0.197$ as $\gamma$ goes from $0$ to $1$. This shows that $\kappa_\gamma$ is not monotone in general. $\square$

**Remark 11.38.** The non-monotonicity of curvature is a subtle point. It means that the geometry can become more or less "curved" as $\gamma$ varies, depending on the specific triple.

## 11.6 The $\gamma$-deformation as a continuous deformation

We now interpret the $\gamma$-deformation as a continuous deformation of metric structures.

**Definition 11.39 (Continuous deformation).** A **continuous deformation** of quasi-metrics on $\mathcal{B}$ is a continuous map $\gamma \mapsto d_\gamma$ from $[0, 1]$ to the space of quasi-metrics on $\mathcal{B}$, equipped with the topology of pointwise convergence.

**Proposition 11.40.** The $\gamma$-family is a continuous deformation of quasi-metrics.

*Proof.* $d_\gamma^2 = d^2 + \gamma^2 D^2$ is continuous in $\gamma$ (Proposition 10.25), so $d_\gamma$ is continuous. $\square$

**Proposition 11.41 (Continuity of balls).** For fixed $b, r$, the ball $B_\gamma(b, r)$ varies continuously in $\gamma$ in the sense that

$$\lim_{\gamma' \to \gamma} B_{\gamma'}(b, r) = B_\gamma(b, r)$$

in the Hausdorff metric (assuming $\mathcal{B}$ is compact).

*Proof.* $d_\gamma$ is continuous in $\gamma$, so the sublevel sets $B_\gamma(b, r) = \{b' : d_\gamma(b, b') < r\}$ vary continuously. $\square$

**Remark 11.42.** The continuity of balls means that the geometry of the $\gamma$-family varies continuously with $\gamma$, at least at the level of balls. Topological changes (phase transitions) can still occur abruptly, but they are changes in the *topology*, not in the *balls*.

**Remark 11.43 (Metric continuity vs. topological discontinuity).** The $\gamma$-family is a continuous deformation of metrics, but not a continuous deformation of topologies. The metric varies smoothly, but the topology can jump at phase transitions. This is the origin of the "phase transition" phenomenon.

## 11.7 The $\gamma$-family and the basepoint

We close this section by noting the basepoint independence of the $\gamma$-geometry.

**Proposition 11.44.** All $\gamma$-geometric quantities—balls, topologies, geodesics, diameters, curvatures—are independent of the choice of basepoint.

*Proof.* They depend only on $d_\gamma$, which is basepoint-independent (Proposition 10.47). $\square$

**Remark 11.45.** The basepoint independence is a manifestation of the gauge invariance of the theory. The $\gamma$-geometry is an observable, independent of the choice of potential.

**Remark 11.46 (Gauge invariance of the $\gamma$-geometry).** Since $d_\gamma$ depends on $d$ and $D$, and $d$ is gauge-invariant while $D$ is gauge-dependent, the $\gamma$-geometry is *not* gauge-invariant in general. Under a gauge transformation $\psi \mapsto \psi + \chi$, the debt shifts to $D + \delta\chi$, and $d_\gamma$ changes accordingly. The gauge-invariant content of the $\gamma$-geometry is the $\gamma = 0$ slice (the pure cost), which is gauge-invariant. For $\gamma > 0$, the $\gamma$-geometry is gauge-dependent.

This is consistent with the general principle established in Chapter 9: the gauge-invariant content of the complex quasi-metric is precisely the real part $d$.

## 11.8 Examples

We illustrate the $\gamma$-geometry with examples.

**Example 11.47 (Phase transition).** In Example 11.16, we found a phase transition at $\gamma_c = 0.5$. At this value, the point $3$ leaves the ball $B_\gamma(1, 2.5)$. The topology $\tau_\gamma$ changes: for $\gamma < 0.5$, the ball contains both $2$ and $3$; for $\gamma > 0.5$, it contains only $2$.

**Example 11.48 (Path transition).** In Example 11.24, we found a path transition at $\gamma_c = \sqrt{5}/3 \approx 0.745$. For $\gamma < \gamma_c$, the indirect path $1 \to 2 \to 3$ is shorter; for $\gamma > \gamma_c$, the direct path $1 \to 3$ is shorter.

**Example 11.49 (Three-point space).** Let $\mathcal{B} = \{1, 2, 3\}$ with

$$d = \begin{pmatrix} 0 & 1 & 3 \\ 1 & 0 & 1 \\ 3 & 1 & 0 \end{pmatrix}, \qquad D = \begin{pmatrix} 0 & 0 & 4 \\ 0 & 0 & 0 \\ -4 & 0 & 0 \end{pmatrix}.$$

Then:

- $d_\gamma(1, 2) = 1$, $d_\gamma(2, 3) = 1$, $d_\gamma(1, 3) = \sqrt{9 + 16\gamma^2}$.
- The indirect path $1 \to 2 \to 3$ has cost $2$.
- The direct path $1 \to 3$ has cost $\sqrt{9 + 16\gamma^2} \ge 3 > 2$.
- So the indirect path is optimal for all $\gamma \in [0, 1]$. No path transition.

**Example 11.50 (Curvature non-monotonicity).** From Proposition 11.37: with $d(b_i, b_j) = 1$, $D(b_i, b_j) = 0$; $d(b_j, b_k) = 1$, $D(b_j, b_k) = 0$; $d(b_i, b_k) = 1.5$, $D(b_i, b_k) = 1$, the curvature decreases from $0.5$ at $\gamma = 0$ to $0.197$ at $\gamma = 1$. This illustrates the non-monotonicity of curvature.

## 11.9 Summary

We summarize the $\gamma$-geometry in a single table.

| **Quantity** | **Definition** | **Dependence on $\gamma$** |
|---|---|---|
| $\gamma$-ball | $B_\gamma(b, r)$ (Ch. 10, Def. 10.30) | Nested, shrinking |
| $\gamma$-topology | $\tau_\gamma$ (Ch. 10, Def. 10.33) | Monotone coarsening |
| Phase transition | Topology change | Isolated values |
| $\gamma$-geodesic | Minimizer of $\sum d_\gamma$ | Changes at path transitions |
| Path transition | Optimal path change | Isolated values |
| $\gamma$-diameter | $\sup d_\gamma$ | Non-decreasing |
| $\gamma$-curvature | $\kappa_\gamma$ | Not monotone |
| Deformation | $\gamma \mapsto d_\gamma$ | Continuous in metric, discontinuous in topology |

**Key results:**

- **Phase transitions** (Definition 11.1): values of $\gamma$ at which the topology changes.
- **Existence of transitions** (Proposition 11.7): if $\tau_0 \neq \tau_1$, then there exists at least one phase transition.
- **Finitely many transitions for finite spaces** (Proposition 11.9): if $\mathcal{B}$ is finite, the critical set is finite.
- **Ratio characterization** (Theorem 11.14): phase transitions are determined by crossings of the debt-to-cost ratios.
- **Path transitions** (Definition 11.22): values of $\gamma$ at which the optimal path changes.
- **Diameter monotonicity** (Proposition 11.29): the diameter is non-decreasing in $\gamma$.
- **Curvature non-monotonicity** (Proposition 11.37): the curvature is not monotone in $\gamma$.
- **Metric continuity** (Proposition 11.40): $d_\gamma$ is continuous in $\gamma$.
- **Topological discontinuity** (Remark 11.43): the topology can jump at phase transitions.
- **Basepoint independence** (Proposition 11.44): all $\gamma$-geometric quantities are basepoint-independent.
- **Gauge dependence** (Remark 11.46): the $\gamma$-geometry is gauge-dependent for $\gamma > 0$.

The $\gamma$-geometry is the study of how the geometry of belief space depends on the parameter $\gamma$. It is the bridge between the complex quasi-metric (Chapter 7) and the polar decomposition and topology lattice (Part V).
